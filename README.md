# SILA Картинг — Дашборд

Аналитический дашборд для картинг-центра SILA. Данные загружаются из Google Sheets в реальном времени.

## Запуск локально

```bash
npm install
npm run dev
```

Открыть: [http://localhost:3000](http://localhost:3000)

## Деплой на Vercel

1. Подключить репозиторий в [vercel.com](https://vercel.com)
2. Нажать Deploy — env-переменные не нужны, таблица публичная

## Стек

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Recharts
